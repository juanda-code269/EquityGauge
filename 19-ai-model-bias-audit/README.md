# Model Equity Audit Lab

Group-level accuracy, precision, recall/TPR, false-positive rate, false-negative rate, selection rate, max–min disparities, model comparison, and threshold trade-offs. Use synthetic trained models or upload labels, groups, and scores.

```bash
pip install -r requirements.txt
streamlit run app.py
```

No single disparity metric proves a model fair or unfair; a legitimate audit needs context, governance, uncertainty, and affected stakeholders.
